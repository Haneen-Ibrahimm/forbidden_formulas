Forbidden Formulas

A horror-themed escape room game for revising pharmaceutical solutions (Pharmaceutics I, Lectures 1 to 3).

Play: https://forbidden-formulas.pages.dev/

About

You are locked in a midnight dispensary. Answer two questions in each of four rooms to collect a secret digit, then enter the four digits at the final lock to escape.

Topics Covered
Active pharmaceutical ingredients and excipients
Pharmaceutical water grades (purified water and water for injection)
Syrups and aromatic waters
Ophthalmic solutions and non-aqueous solvents
Run Locally

Download the repository and open index.html in any web browser. An internet connection is needed to load fonts and styling.

Built With

HTML, CSS, JavaScript, and Tailwind CSS. No installation required.

Note

For classroom learning and revision only.
